# Simmer

An iPad-first cooking companion. Recipe library and cooking progress are stored on your device. Export backups before clearing browser data or switching devices.

Static app files live in `docs/`. Serve that folder locally, or configure GitHub Pages to deploy from `main` / `docs`.

No API keys, accounts, or cloud recipe synchronization are included. Custom recipes use editable sequential timing and text guidance. The sample recipe includes generated visual references.
